# История обновлений проекта Atomy Елена Федеряшина

## 22 февраля 2026, 23:00

**Что было сделано:**
Масштабная переработка сайта по шаблону MLLM — из сайта-визитки в полноценный интернет-магазин/лендинг дистрибьютора Atomy.

**Перечень изменений:**

### Новые компоненты
- `Hero.jsx` — полностью переделана в стиле MLLM: тёмно-синий градиент, крупный заголовок «Гипермаркет из Южной Кореи», статистика (15+ лет, 50+ стран, 20M+ клиентов, 500+ товаров), бейджи (Корейское качество, Бесплатная доставка, Скидки до 80%)
- `Catalog.jsx` — полноценный каталог из 30 товаров с поиском, фильтрами по категориям (Здоровье, Красота, Гигиена, Питание), карточками товаров (изображение, цена до/после регистрации, скидка, PV), кнопкой «Показать ещё»
- `PriceCompare.jsx` — блок сравнения цен Atomy vs обычные магазины (5 сравнений с подсчётом экономии)
- `Reviews.jsx` — горизонтальная карусель из 8 отзывов покупателей с кнопками прокрутки
- `Certificates.jsx` — 6 карточек с гарантиями качества (ISO 22716, KFDA, Vegan, KAERI, клинические тесты)
- `FAQ.jsx` — 8 вопросов-ответов в формате аккордеона (что такое Атоми, доставка, оплата, возврат и т.д.)
- `Consultant.jsx` — блок «Ваш консультант» с фото Елены, контактами (телефон, Telegram, VK), кнопкой регистрации
- `Footer.jsx` — CTA-секция «Готовы начать экономить?» + футер с копирайтом и соц.сетями

### Парсер товаров
- Создан `scripts/fetch-products.mjs` — скрипт на Playwright для автоматического парсинга товаров с atomy.ru (название, цена до/после регистрации, PV, изображение 610x610)
- Спарсено 30 товаров из 4 категорий
- Данные сохраняются в `src/data/products.json`

### GitHub Actions
- Создан `.github/workflows/update-catalog.yml` — автоматический запуск парсера каждый понедельник в 06:00 UTC, коммит изменений при обновлении данных
- Также доступен ручной запуск через `workflow_dispatch`

### Навигация
- `Navbar.jsx` обновлён: ссылки на новые секции (Каталог, Сравнение цен, Отзывы, Сертификаты, FAQ, Контакты), белый текст на тёмном фоне Hero с переключением на тёмный при скролле

### Удалённые компоненты
- `About.jsx`, `Benefits.jsx`, `RegistrationSteps.jsx`, `Contacts.jsx`, `Products.jsx` — заменены новыми секциями

**Проблемы и решения:**
- Atomy.ru блокирует парсинг категорий → решено через индивидуальный парсинг страниц продуктов по кодам
- Имена товаров парсились как «Изображение товара» (alt-текст) → исправлено на парсинг из `<title>` страницы
- Изображения загружались в 40x40 → автоматическая замена URL на 610x610

**Контекст:**
Переработка выполнена по просьбе пользователя, который хотел сайт в стиле шаблона MLLM (платный конструктор для дистрибьюторов Atomy). Основные требования: полный каталог с автообновлением, сравнение цен, отзывы, FAQ, сертификаты, блок консультанта. Реферальная ссылка зашита во все CTA-кнопки.

# История обновлений проекта Atomy Alyona

## 22 февраля 2026, 16:00

**Что было сделано:**
Полный редизайн и рефакторинг сайта-визитки Atomy Alyona.

**Перечень изменений:**
- Удалены старые CSS-файлы и разрозненные React-компоненты.
- Настроен `Tailwind CSS` (v4) с кастомной темой цветов Atomy (синий, белый, голубой).
- Установлены `framer-motion` для плавных анимаций и `lucide-react` для иконок.
- Созданы базовые переиспользуемые UI-компоненты: `Button.jsx`, `Card.jsx`, `Section.jsx`, `Typography.jsx`.
- Разработана новая секция `Hero` с градиентным фоном и парящими карточками.
- Добавлена навигационная панель `Navbar` с поддержкой адаптивного мобильного меню.
- Сверстаны блоки:
  - `About` (Информация об Алёне со статусом мастера продаж).
  - `Products` (Хиты продаж с фильтрацией по категориям).
  - `Benefits` (Преимущества продукции Atomy).
  - `RegistrationSteps` (Простые шаги для старта).
  - `Contacts` & `Footer` (Кнопки-ссылки на мессенджеры и социальные сети).
- Настроен плавный скроллинг `scroll-smooth` в `index.html`.
- Добавлен шрифт `Inter` через Google Fonts.

**Проблема:**
Текущая версия визитки была слишком простой и не соответствовала уровню премиального бренда Atomy. Кроме того, отсутствовала удобная структура компонентов и мобильная навигация, а старые CSS стили было трудно поддерживать.

**Как проблема была решена:**
Мы полностью переписали фронтенд-часть с использованием Tailwind CSS для быстрой и гибкой стилизации, а Framer Motion позволил добавить эффекты "парящих элементов" и плавное появление при скролле. Код был разбит на логические модули и UI-библиотеку, что значительно упростило дальнейшую поддержку и масштабирование проекта.

**Контекст:**
Сайт-визитка должна привлекать новых клиентов и партнеров. Современный премиальный дизайн с эффектом стекла (glassmorphism) и фирменными цветами Atomy повышает доверие пользователей и лучше презентует продукцию абсолютного качества. Деплой по-прежнему осуществляется через GitHub Pages при пуше в `main` ветку.
